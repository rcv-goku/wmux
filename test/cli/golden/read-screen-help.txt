Usage: cmux read-screen [--surface <id|ref|index>] [--scrollback] [--lines <n>] [--selection]

Print terminal text as plain text (default: the visible screen).

Options:
  --surface <id|ref|index>      Surface to read (default: $CMUX_SURFACE_ID)
  --workspace <id|ref|index>    Workspace context (default: $CMUX_WORKSPACE_ID)
  --window <id|ref|index>       Window context for refs and indexes
  --scrollback                  Include the scrollback history
  --lines <n>                   Only the last n lines (n > 0; implies
                                --scrollback)
  --selection                   Print the active selection instead (text-only
                                alias of read-selection; not with --scrollback
                                or --lines)
  --json                        Print the full response
