Usage: cmux paste [--surface <id|ref|index>] [--submit] [--force] [<text>|-]

Paste text into a terminal surface the way the paste shortcut does. The CLI
leaves the text alone; the terminal wraps it in bracketed-paste markers if
the running program asked for them, turns each line break into Enter if it
did not, and blanks out unsafe control characters. Without a text argument,
or with - given before --, the text comes from stdin, read once before the
app is contacted. More than 15 MiB is refused.

Options:
  --surface <id|ref|index>      Target surface (default: $CMUX_SURFACE_ID)
  --workspace <id|ref|index>    Workspace context (default: $CMUX_WORKSPACE_ID)
  --window <id|ref|index>       Window context for refs and indexes
  --submit                      Then press the submit key the agent expects
  --force                       Skip the draft guard
  --json                        Print the full response

Examples:
  git diff | cmux paste --surface surface:2
  cmux paste --submit "Review this"
