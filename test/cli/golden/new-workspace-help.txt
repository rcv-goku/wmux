Usage: cmux new-workspace [--name <title>] [--description <text>] [--cwd <path>] [--command <text>] [--env KEY=VALUE]... [--env-file <path>]... [--layout <json>] [--window <id|ref|index>] [--focus <true|false>] [--group <id|ref>] [--group-placement afterCurrent|top|end] [--group-reference <workspace>]

Create a workspace in the caller's window (or --window) and print
"OK <workspace>". Legacy alias of "cmux workspace create", which takes the
same flags.

Options:
  --name <title>                Custom title
  --description <text>          Workspace description
  --cwd <path>                  Working directory (relative to the current
                                directory)
  --command <text>              Typed into the new interactive shell followed
                                by Enter; the shell stays open afterwards.
                                Blank text is ignored; --layout wins
  --env KEY=VALUE               Workspace environment variable (repeatable);
                                overrides values from --env-file
  --env-file <path>             KEY=VALUE lines; blank lines and # comments
                                are ignored, a leading "export " is stripped
                                (repeatable)
  --layout <json>               Split layout (JSON) or saved layout name
  --window <id|ref|index>       Window to create the workspace in
  --focus <true|false>          Select the new workspace (default: false,
                                created in the background); a bare --focus
                                means true, --no-focus means false
  --group <id|ref>              Add it to a workspace group
  --group-placement <where>     afterCurrent, top (default) or end
  --group-reference <workspace> Reference workspace for afterCurrent
  --worktree <branch>           wmux: open the workspace in a git worktree
                                for <branch>
  --repo <path>                 wmux: repository for --worktree (default: the
                                current directory)
  --json                        Print the result as JSON

Workspace environment variables reach every shell in the workspace, are
saved with the session (in plaintext) and never override the CMUX_*
variables, TERM, COLORTERM or TERM_PROGRAM.
