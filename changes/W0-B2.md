# W0-B2: e2e harness completion per spike S2

Test infrastructure only; no change to wmux itself.

- The focus sampler watches the whole process tree of a test instance (wmux, conhost, shells,
  msedgewebview2; descendants refreshed every 250 ms, exited PIDs kept, PID reuse ruled out by
  creation time) on a per-monitor-v2 DPI-aware thread; a window of the tree in the foreground
  fails the test with "focus stolen by test instance" and kills the tree.
- New visibility guard: a visible, uncloaked, on-monitor top-level window of the tree fails the
  test with "visible test window"; cloaked and (-32000,-32000) windows are accepted and the
  hidden mode in use is reported per instance (`hidden_mode`).
- `Get-WmuxScreenshot` is DWMWA_CLOAKED-aware: it reports the window placement and a terminal
  "not blank" check that is inconclusive unless the window is cloaked on a monitor, and it no
  longer hangs on a stuck UI thread.
- `Stop-WmuxInstance` kills orphaned tree members (WebView2 outlives its host), waits until none
  is listed, and deletes the instance root in the background when files stay locked;
  `run.ps1` sweeps roots left by dead runs and honours a `# budget-sec:` header.
- New suites replacing the W0 dogfood gate (AF-19): `legacy/legacy-compat` (all 37 legacy JSON
  commands, reply shapes pinned in `test/e2e/fixtures/legacy/`), `legacy/plus-verbs` (every
  legacy `+verb` through `wmux.exe` and `cli\wmux.com` against goldens captured from `aa1f532`
  in `test/e2e/fixtures/plus-verbs/`), `regression/w0-regression` (scripted legacy checklist)
  and `_selftest/isolation` (guards, cleanup, sweep, and untouched `%LOCALAPPDATA%` state).
