# W0-A1: App and ipc extraction

- New test-mode environment for automation (ARCHITECTURE.md ADR-12.3):
  `WMUX_TEST_MODE=1` (no global hotkey, no tray icon or balloons, no
  update check, no sounds, in-process clipboard, message boxes
  auto-answered with their default button), `WMUX_TEST_HIDDEN=1`
  (windows are DWM-cloaked at the primary work-area origin with a
  1600x1000 client size clamped to the work area, never activated, not in
  the taskbar or Alt-Tab, and do not save or restore their placement),
  `WMUX_TEST_TOAST_SINK=<file>`
  (desktop notifications that test mode does not show are appended as
  JSON lines), `WMUX_TEST_SESSION_RESTORE`, and
  `WMUX_DISABLE_SESSION_RESTORE` / `CMUX_DISABLE_SESSION_RESTORE`.
- `WMUX_STATE_DIR=<dir>` moves `window-state`, `session-state.json`,
  `scrollback\` and the WebView2 user data under `<dir>`;
  `WMUX_CONFIG_DIR` is reserved for the wmux config directory. Without
  them nothing moves.
- The legacy `select-layout` pipe command now answers `NoWindow` when no
  window exists instead of leaving the client waiting forever.
- `wmux +browser` no longer double-frees when several wmux instances are
  running.
- Pipe requests still queued when wmux exits are now freed.
