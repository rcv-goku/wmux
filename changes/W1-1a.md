- New: wmux serves the cmux v2 protocol on `\\.\pipe\wmux-<channel>-<sidhash8>-s<session>` (`system.ping`, `system.capabilities`, cmux error codes, UUID/ref/index selectors that fail closed, 64+64 connection admission, polling rate limit, 10 s UI deadlines) and names it in `STATE\run\instance.json`.
- New: one instance per channel: starting `wmux.exe` again (for example with a folder) hands the launch to the running instance, which opens the folder as a workspace or a new window, and the second process exits.
- New: `cmux ping` (and every CLI command) finds the running instance without `CMUX_SOCKET_PATH` through `instance.json`.
- Changed: the legacy `wmux-ipc-<pid>` pipe serves many clients at once and the legacy JSON commands also work on the control pipe, with unchanged replies; `socket-control = read-only` refuses a command before any side effect.
- Changed: the log file `STATE\logs\wmux.log` starts during app startup instead of with the first window.
- Test mode: the `wmux.debug.*` hooks (`ready`, `app.quit`, `focus_state`, `layout`, `type`, `key`, `menu.list`, `menu.invoke`, `dialogs.*`, `clipboard.*`, `timers`, `external_open.list`, `sounds.list`) for automation.
