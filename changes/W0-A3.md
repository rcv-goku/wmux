# W0-A3: Skeleton (registries, handles, events, pre-wiring)

- A `wmux:<action-id>` keybinding action is accepted in the Ghostty
  configuration (`keybind = ctrl+b=wmux:newSurface`, an argument after a
  second colon). It has no effect yet: the actions get their handlers in
  Wave 1.
- Context menus act on what was right-clicked even if that tab, pane or
  workspace closed while the menu was open and a new one took its memory;
  the command then does nothing.
- No other user-visible change: the release reorganizes wmux internally
  (object ids, the event bus, the RPC, action and UI registries, start-up
  hooks) so that later releases can add features without touching the
  core. The legacy `wmux +...` commands and their replies are unchanged.
