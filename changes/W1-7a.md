# W1-7a: session v3 core

wmux now saves the whole app in `STATE\session\session.json` (schema v3) and restores it on
launch.

- Autosave every 8 seconds when something changed (never while idle), written atomically on a
  background thread with a `session.json.bak` backup; a full save when the last window closes
  and on Windows logoff or shutdown. Closing one of several windows no longer overwrites the
  session with that window alone.
- Restore on launch of every window (placement fitted to its monitor's work area), workspace
  (title, description, directory, pin, group, selection), split (ratio within 1%), pane (focus,
  zoom) and tab (title, selected tab), with the saved UUIDs and refs; terminals start in their
  saved directory, else the workspace directory, else `%USERPROFILE%`, with the saved surface
  UUID. The visible workspace's terminals start first, the others one every 30 ms.
- Skipped with `WMUX_DISABLE_SESSION_RESTORE`/`CMUX_DISABLE_SESSION_RESTORE`, the new setting
  `wmux.session.restoreOnLaunch: false`, a launch with a path, URL, `-e`, `--command` or
  `--working-directory`, and in test mode without `WMUX_TEST_SESSION_RESTORE=1`.
- A restore that did not finish (`session.restoring` left behind) is skipped once: the snapshot
  moves to `session.crashed-<ms>.json` and a `session.crashed` notice is shown; the next launch
  restores normally. An unclean exit (`session.running` of a dead process) shows a notice.
- One-time migration of the old `session-state.json` (v2 or v1, with the old `window-state`
  geometry) into v3; the old file is renamed `.migrated`. The legacy `session-restore` command
  now restores every workspace with its splits (it used to lose background workspaces).
- Window references (`window:N`, `surface:N`, ...) are reserved in `STATE\run\handles.json`, so a
  crash never hands out a ref twice.
- New setting `wmux.session.autosave` (default `true`).
- Windows can relaunch wmux after an update or a restart-capable reboot
  (`RegisterApplicationRestart`).
