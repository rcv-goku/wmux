Usage: cmux move-workspace-to-window --workspace <id|ref|index> --window <id|ref|index>

Move a workspace into another window and print "OK <workspace> <window>".
A workspace index counts in the caller's (or the active) window.

Options:
  --workspace <id|ref|index>   Workspace to move (default: $CMUX_WORKSPACE_ID)
  --window <id|ref|index>      Target window (required)
  --json                       Print the result as JSON
