Usage: cmux close-workspace --workspace <id|ref|index> [--window <id|ref|index>] [--force]

Close a workspace and print "OK <workspace>". Legacy alias of
"cmux workspace close", except that the workspace is required: give it as
--workspace (or as the first argument); a blank --workspace "" means the
caller's workspace ($CMUX_WORKSPACE_ID).

Options:
  --workspace <id|ref|index>   Workspace to close (required)
  --window <id|ref|index>      Window that resolves an index
  --force                      Close even when a running process would be
                               killed
  --json                       Print the result as JSON
