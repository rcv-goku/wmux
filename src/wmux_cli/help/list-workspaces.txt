Usage: cmux list-workspaces [--window <id|ref|index>]

List the workspaces of a window (default: the caller's or the active
window), one per line:

  * workspace:2  <title>  [ssh:connected]  [selected]

"*" and "[selected]" mark the selected workspace; "[<transport>:<state>]"
appears only for remote workspaces. Prints "No workspaces" when empty.
Legacy alias of "cmux workspace list".

Options:
  --window <id|ref|index>   Window to list
  --json                    Print the result as JSON; workspace UUIDs stay
                            unless --id-format is given (environment
                            variables are never included)
