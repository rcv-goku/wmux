## What
1. `src/apprt/win32/fast_tests.zig` imports the two logic test indexes W0-A2 created,
   `model/logic/tests.zig` (std-only `arith.zig`, `titles.zig`) and
   `ui/tabbar/logic/tests.zig` (std-only `geometry.zig`), one sorted line each.
2. `scripts/check-manifest.ps1` stops requiring that `model/logic/fake.zig` be referenced
   from `model/logic/tests.zig`: the fake model graphs of ADR-12.1 are referenced from the
   layer's full-suite test block (`ui/Window.zig`) instead. Proposed rule: a `logic/`
   file named `fake.zig` is exempt from the "referenced from its logic/tests.zig" check.
   Alternative (lead architect, Appendix F entry): move the file to `model/fake.zig` and
   change ADR-12.1 and section 15.5, which name `model/logic/fake.zig`.

## Why
- ADR-12.1 and `check-manifest.ps1` require a `logic/tests.zig` per `logic/` directory,
  referencing every file there and reachable from `fast_tests.zig`. W0-A2 created
  `model/logic/` (ADR-1.1, ADR-12.1) and `ui/tabbar/logic/` (the one shared tab bar
  geometry of ADR-11.1), but `fast_tests.zig` is frozen for W0-A2.
- `arith.zig`, `titles.zig` and `geometry.zig` are std-only and belong in test-fast:
  `zig test src/apprt/win32/model/logic/tests.zig` (25 tests) and
  `zig test src/apprt/win32/ui/tabbar/logic/tests.zig` (9 tests) pass as standalone,
  std-only roots, which is exactly the test-fast constraint.
- `fake.zig` cannot join test-fast. It builds real model objects (ADR-12.1: "builds
  window/workspace/pane/tab graphs"; the W0-A2 task names `model/logic/fake.zig`), and
  `model/Pane.zig`/`model/Workspace.zig` hold a `SplitTree` from
  `src/datastruct/split_tree.zig`, outside the test-fast module root
  (`src/apprt/win32`), which Zig rejects ("import of file outside module path"). So it
  can never be referenced from a fast-reachable `logic/tests.zig`, as check-manifest
  demands of every `logic/*.zig`. ADR-1.2 ("logic files: std only, run in test-fast") and
  ADR-12.1 (the fake model lives in `model/logic/`) conflict for this one file.

## Stub until merged
- W0-A2 ships `model/logic/tests.zig` and `ui/tabbar/logic/tests.zig` and references them,
  plus `model/logic/fake.zig`, from `ui/Window.zig`'s test block, so the full suite and
  the CI `"unit: "` filter already run every model and tab bar test.
- Until this lands, `pwsh scripts/check-manifest.ps1` reports three errors on the W0-A2
  head (master before W0-A2: none): `model/logic/fake.zig` is not referenced from
  `model/logic/tests.zig`, and the two indexes are not reachable from `fast_tests.zig`.
  Part 1 clears the last two, part 2 the first. Checked on a copy of the W0-A2 head with
  both parts applied: `check-manifest.ps1` reports 0 errors and 0 warnings.

## Impact and risks
- test-fast gains 32 std-only tests (well under a second). No behavior change.
- Merge order: part 1 must land with or after W0-A2 (the indexes must exist). Nothing else
  depends on it.
