## Design notes
- Plan entry `WP-12-key-router` (`docs/arch/plan/WORKPACKAGES.json`), executor plan, est. size L
  (11.8 units).
- ADR-8.2-8.7: router.zig called from message_loop.preTranslate and WebView2 accelerators (entry
  API), text-producing keys never match, AltGr "text always wins" via ToUnicodeEx(0x4) tables
  rebuilt on WM_INPUTLANGCHANGE, contexts and when-clauses (W0-P3 parser), 1.5 s chords with tab-bar
  hint and Esc cancel, performable pass-through, effective bindings = wmux.json literal
  shortcuts.bindings + explicit Ghostty keybinds suppressing router defaults + catalog defaults;
  handlers for every existing behavior in the 13 pre-seeded modules (chrome handlers call the
  ui/sidebar and ui/right_sidebar facades implemented by W1-8b/8c/8d), Ghostty tab semantics
  wmux.ghosttyTabActions (goto_tab off-by-one fixed, performAction returns the real bool),
  Keybinds.init win32 pruning, Shift+Insert repaired, wmux.action.run and wmux.shortcuts.list.
  Critic fixes: a one-time "keymap changed" notice links to the presets, and the wmux-classic preset
  (W0-P3 data) applied through wmux.json restores Ctrl+T/W/B, Alt+1..9 and Ctrl+Enter.
