## Design notes
- Plan entry `WP-13-sidebar-focus-dpi` (`docs/arch/plan/WORKPACKAGES.json`), executor plan, est.
  size M (3 units).
- ADR-11.4/11.5: focusSidebar keyboard mode (Up/Down, Enter selects and focuses the pane, Esc
  returns, F2 renames, Ctrl+Up/Down reorders, focus ring); one TOOLTIPS_CLASSW per window with
  TTF_TRACK shown only for truncated row titles and pane tabs (title, cwd, agent status);
  WM_DPICHANGED/WM_GETDPISCALEDSIZE chrome window hook applying the suggested rect, rebuilding text
  formats, SetDpi on render targets, rescaling tab bars and overlays, forwarding to terminal
  surfaces and WebView2 bounds (fixes ui-model 8.1#5).
- Depends on: W1-IF, W1-8b, W1-5a, W1-6c.
