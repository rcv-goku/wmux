## Design notes
- Plan entry `WP-04-spike-foldins-isolation` (`docs/arch/plan/WORKPACKAGES.json`). Lands every
  W0-time correction from the spikes and the critic in the hot-file lane after W0-A3 (the web-app
  pre-builds of plan wave 4 touched only `src/web` and `test/web` and are merged). Read ADR-12.3
  (amended per S2), ADR-14.3 (link list, amended per S1), ADR-11 with AF-10 (S7), ADR-2.3/2.4 with
  AF-22 (model), AF-16 (Appendix G additions), plan note 7 (isolation) and the spike notes
  `docs/arch/spikes/S1-toasts.md`, `S2-hidden-instances.md`, `S7-d2d-sidebar-child.md`.
- S2 cloaked hidden mode (FOLLOWUPS: not implemented yet, hidden windows still report
  `IsWindowVisible` true). Apply `docs/arch/spikes/proto/S2/wmux-hidden-mode.patch` to the
  restructured tree: hidden top-level windows are placed fully inside the primary work area with the
  client clamped to it, cloaked with `DWMWA_CLOAK` right after `CreateWindowExW` and verified with
  `DWMWA_CLOAKED` (the -32000 fallback marks GL captures inconclusive); focus policy gate
  (`SetFocus` only when the root is the active window); a thread `WH_CBT` hook (`HCBT_CREATEWND`
  moves user32-created windows off-screen, `HCBT_ACTIVATE` is blocked).
- Isolation: no placement restore/save and no session save on `WM_CLOSE` in test mode unless
  `WMUX_TEST_SESSION_RESTORE=1`; every legacy state path goes through `app/paths.zig`; the update
  check is off.
- Sinks (AF-16): `WMUX_TEST_EXTERNAL_SINK` for `ShellExecute`/`open_url`, `WMUX_TEST_SOUND_SINK` for
  `MessageBeep`/`PlaySound`; `app/dialogs.zig` is the only `IFileDialog`/`MessageBox` entry, answered
  from `WMUX_TEST_FILE_DIALOG` (default cancel). `app/logger.zig` writes `STATE\logs\wmux.log`
  (8 MiB x 2 rotation, `WMUX_LOG` level).
- S7: `WS_CLIPSIBLINGS` on every child of the top-level window.
- S1 link list (FOLLOWUPS: verify what W0-A3 already changed): `src/build/SharedDeps.zig` no longer
  links `runtimeobject` or `combase` (its comment cites S1: WinRT through
  `extern "api-ms-win-core-winrt-*"`, COM through `extern "ole32"`). Verify that the debug and
  ReleaseFast `wmux.exe` import neither DLL, and touch `SharedDeps.zig` only if a gap remains.
- Model (FOLLOWUPS: the Group/pinned check; AF-22): `Workspace.group`/`pinned`, `Group` (`handle`,
  `name`, `collapsed`, `pinned`, `anchor`) and `Window.groups` exist since W0-A3; check them against
  ADR-2.3 and add `model/logic/display_order.zig` (pinned first, then groups flattened in display
  order) so the W1-1a index semantics of ADR-2.4 are final. `display_order.zig` stays std-only
  (ADR-1.2) and is listed in `model/logic/tests.zig`, which `fast_tests.zig` reaches; the acceptance
  test that builds graphs with `model/logic/fake.zig` runs in the full suite (ruling D1).
- e2e checks run through the W0-B2 harness; never activate a window or steal focus (G4).
