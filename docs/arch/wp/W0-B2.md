## Design notes
- Plan entry `WP-02-harness-hardening` (`docs/arch/plan/WORKPACKAGES.json`). A delta on the merged
  W0-B harness, which already redirects `LOCALAPPDATA`/`XDG_CONFIG_HOME`, seeds `update_check_at`,
  captures with a DPI-aware `PrintWindow` and kills the process tree. Read ADR-12.3, ADR-12.4,
  Appendix D, spike S2 (`docs/arch/spikes/S2-hidden-instances.md`; harness prototype
  `docs/arch/spikes/proto/S2/run-wmux-hidden.ps1` with `S2Native.cs`), Appendix F.2 AF-5, AF-11 and
  AF-19, and plan note 7 (isolation).
- From S2: the focus sampler watches the whole process tree (descendants refreshed every 250 ms,
  exited PIDs kept, conhost, shells and msedgewebview2 included); a visibility guard fails any
  visible, uncloaked, on-monitor window of the tree; screenshot assertions read `DWMWA_CLOAKED` (GL
  checks are inconclusive when the window is not cloaked); after a graceful stop, orphan
  msedgewebview2 processes are cleaned up and the run root is deleted asynchronously, with a sweep of
  stale roots. The app side of the cloaked hidden mode comes later in W0-A4: until then hidden
  windows sit at (-32000, -32000), visible but on no monitor, which the guard accepts just as it
  accepts cloaked windows.
- New suites replace human dogfooding in W0 (AF-19): `legacy-compat` (all 37 legacy JSON commands of
  ADR-3.7, reply shapes pinned as fixtures under `test/e2e/fixtures/legacy/`), `plus-verbs` (every
  `+verb` through `wmux.exe` and through `cli\wmux.com`, output compared with goldens captured from
  `aa1f532` under `test/e2e/fixtures/plus-verbs/`), `w0-regression` (scripted legacy checklist:
  splits, tabs, workspaces, send/read-screen, browser open/eval/snapshot, notify,
  status/progress/log, session save/restore, layouts, sync-input, break/move pane, right sidebar) and
  the isolation self-test.
- FOLLOWUPS (2026-10-16): W1-2a is merged (`wp/cf-cli`, `0417d37`), so `plus-verbs` runs every
  `+verb` through `cli\wmux.com` now; "skipped: legacy CLI not present" applies only to a build that
  does not stage `cli\wmux.com`. Divergences caused by the W1-2a `legacy_plus` rewrites
  (`+status set|progress`, the old `--tab`/`--pane` meanings, `+notify next` flags,
  `+browser --id/--tab/--split`, `+capture-pane --file`) belong to W1-2b (AF-11: byte-identical
  legacy output): report each as a skip that names W1-2b (`[WmuxSkipException]`), never as a pass,
  and do not edit `src/wmux_cli/**`.
- Known flake until W0-ST's early part lands (ruling D17, ADR-12.7): a one-off hang while closing a
  just-created tab or workspace (the `src/termio/Exec.zig` read-thread teardown race). The runner's
  single retry covers it; do not quarantine W0-B2 suites for it and never add sleeps.
- Instances start only through the harness: hidden (`WMUX_TEST_MODE=1`, `WMUX_TEST_HIDDEN=1`),
  `UseShellExecute=false`, `CreateNoWindow=true`, temporary state and config directories. A test
  never takes OS focus (G4).

- `pwsh test/e2e/run.ps1 -Suite _selftest`: isolation hashes, the visible-window fixture and the

## Done when
- `pwsh test/e2e/run.ps1 -Suite legacy,regression -Parallel 4` passes on a Debug and a ReleaseFast
  build; `plus-verbs` runs through `cli\wmux.com` as well as `wmux.exe`, and its `cli\wmux.com`
  invoker reports "skipped: legacy CLI not present" only when the build under test has no
  `cli\wmux.com`.
- `pwsh test/e2e/run.ps1 -Suite _selftest`: `isolation.e2e.ps1` hashes every file under
  `%LOCALAPPDATA%\ghostty` and `%LOCALAPPDATA%\wmux` before and after
  `-Suite smoke,legacy -Parallel 4` and finds no change (inconclusive when a non-test `wmux.exe`
  ran; CI is authoritative).
- Self-test: a fixture window made visible on purpose fails with "visible test window"; a child
  process of the instance tree taking foreground fails with "focus stolen by test instance".
- After `Stop-WmuxInstance` no `wmux.exe` or `msedgewebview2.exe` of the run is alive
  (`Win32_Process` query) and the root is gone within 60 s.
- `scripts/gate.ps1 -Wp W0-B2` green; `test/e2e/README.md` documents the suites, the sampler and the
  guard; `changes/W0-B2.md` written.
