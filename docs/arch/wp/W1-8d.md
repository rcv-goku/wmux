## Design notes
- Plan entry `WP-13-right-sidebar-host` (`docs/arch/plan/WORKPACKAGES.json`), executor plan, est.
  size M (7.4 units).
- ADR-11.6: child HWND host with a D2D mode bar above a content child; RightSidebarMode registry
  from features (web panel, native Dock or the legacy strip as mode wmux.status); mode, width and
  visibility per window, persisted; invalidation on model events (fixes the stale repaint);
  wmux.rightSidebar.visible only sets the initial state (the toggle always works); show/hide/reorder
  of mode tabs (rightSidebar tab customization keys); positional Ctrl+1..5 under rightSidebarFocus
  with priority routing; wmux.right_sidebar.{get,set,toggle,show,hide,focus}; CLI right-sidebar;
  legacy toggle-right-sidebar flipped to wmux.right_sidebar.toggle honoring the target window.
- Depends on: W1-IF, W1-8b, W1-6c, W1-5a.
- Derived from the old plan ids WP-05-right-sidebar-host (docs/arch/plan/mapping.md).
