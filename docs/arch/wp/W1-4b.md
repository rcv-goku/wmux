## Design notes
- Plan entry `WP-12-config-cli` (`docs/arch/plan/WORKPACKAGES.json`), executor
  external:cfleet-wave1, est. size L (11.8 units).
- ADR-5.6 CLI and the remaining Ghostty interplay: config
  get|set|unset|toggle|cycle|preset|doctor|check|validate|path|docs [--json] offline through
  wmux_proto/json_edit.zig, sidecar write lock + atomic replace,
  --preview/--expect-revision/receipts and undo per cmux config transactions, source per key in get
  --json, policy-locked keys refused, legacy shorthands sidebar-font-size and
  surface-tab-bar-font-size, settingPresets, `config preset <name>` writing only the differences,
  `config reload` -> wmux.config.reload (system module). Ghostty side: JSON keys with
  ghostty_override generate the overrides file; cmux-only Ghostty keys (sidebar-background with
  light:/dark:, sidebar-tint-opacity, sidebar-font-size, surface-tab-bar-font-size) are read from
  the Ghostty files by the settings layer without adding Config.zig keys (G8) and their unknown-key
  diagnostics are suppressed; `config doctor` reports deprecated Ghostty keys and Mac-only cmux
  keys. wmux.debug.notices lists ui/notice.zig notices.
