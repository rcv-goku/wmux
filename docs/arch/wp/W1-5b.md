## Design notes

  est. size L (9.8 units).
- ADR-8.6/8.9 customization: wmux.json literal strokes, cmux.json mac strokes translated by
  mac_translate.zig (cmd -> ctrl+shift, cmd+shift/cmd+opt non-letter/cmd+ctrl -> ctrl+shift+alt,
  cmd+opt+letter -> alt+shift+letter) with collision and terminal-safety drops reported by config

  in test mode; a test hook reports the registration).
