## Design notes
- Plan entry `WP-12-session-scrollback` (`docs/arch/plan/WORKPACKAGES.json`), executor plan, est.
  size M (5.4 units).
- ADR-9.5 with the S3 changes (AF-6): save via the screen formatter (SGR only, OSC/colour OSC
  stripped, CRLF, tail cap 4,000 lines or 400,000 chars) read and written on the session worker,
  replay = sanitize(file) ++ ESC[0m ++ CRLF x rows ++ ESC[H fed in 64 KiB chunks per renderer mutex
  hold on the IO thread before the PTY read thread starts; CMUX/WMUX_RESTORE_SCROLLBACK_FILE is not
  exported when terminal-side replay ran; the dead saveAllScrollback/restoreScrollback path is
  deleted; PageList resizeCols fix lands with its test. Scrollback checkpoints at most every 60 s
  for terminals with new output after 5 s idle; unclean exit merges checkpoints.
  session-previous.json + session.restore_previous + `cmux restore-session` (launch if needed; beep
  when empty); corrupt session.json quarantined to session.unusable-<ms>.json, fallback .bak then
  previous, newer schema preserved. Legacy flips: session-save -> wmux.session.save, session-restore
  -> session.restore_previous; `wmux session save` CLI (K:wmux/session.zig).
