# CLI system commands: offline conformance (W1-2c)

Global and offline commands of `cli\cmux.exe` (`cmux` / `wmux`), checked against the cmux CLI
contract without a running app.

| Command | Socket | Notes |
|---|---|---|
| `help`, `--help`, `-h` | none | top-level usage, every command once under the cmux task groups |
| `help <topic>` | none | one group; unknown topic or extra arguments print the top-level usage (exit 0); `help --help` prints `Usage: cmux help [topic]` |
| `version`, `--version`, `-v` | none | `cmux <version> (<build>) [<commit>]`; `version --help` prints the version (cmux caveat) |
| `guide`, `--skill` | none | embedded Markdown starting `# cmux guide`; `--json`; extra arguments exit 2; `--skill` only in command position |
| `docs [topic]` | none | `Topics:` list; unknown topic is a usage error |
| `welcome` | none | logo, tagline, the default shortcuts, pointer to `cmux shortcuts` |
| `<command> --help`, `-h` | none | `Usage: cmux <command> ...` for every command, also commands whose family is not implemented yet |

## Probe contract (`test/cli/probes.ps1`)

`pwsh test/cli/probes.ps1 [-Exe <cli>] [-Name cmux|wmux|both] [-Json <report>]` runs the cmux
contract probe lists (positive and negative) plus wmux additions, in the cmux and wmux spellings,
with no instance and no socket environment (socket variables point at a pipe that does not exist,
a fresh channel), and fails on a wrong exit code, missing or unexpected text, or any connection
attempt. Exit 0 pass, 1 failure, 2 CLI not found. Gate `-Full` runs it as a contract test.

Adapted probes (wmux does not claim cmux cloud/account families, G2 and Appendix E D19):

| cmux probe | wmux expectation |
|---|---|
| `cmux --help` → `cmux - control cmux via Unix socket` | `... via named pipe` |
| `cloud`/`vm`/`auth`/`remotes`/`remote`/`coderouter`/`feedback`/`glaeda` `--help`, `guide`, `--skill` | exit 2, `not supported on wmux` on stderr |
| `help remote` → `auth <status\|login\|logout\|team>` | must not be listed |
| `surface --help` → `Usage: cmux surface ls ...` | must not be printed (`surface` is `surface-resume` on wmux) |
| `vm exec demo -- --help` must not print `Usage: cmux vm` | unchanged (exit 2, not supported) |

wmux additions: version format, guide `--json`, unknown help topics, `--json`/`--id-format`
around `--help`, usage errors (`guide extra`, `welcome extra`, `docs bogus`, invalid
`--id-format`, `--socket` after the command, missing global values, unknown global options, an
invalid `--focus`), and `send -- --help`/`send -- --version`, which must reach the (absent) socket
instead of printing help or the version.

## Output helpers for command families

- `output.writeDisplay(w, text, output.sanitizeDisplay(json, stdout_is_console))`: ruling D9
  sanitization of single-line display fields (C0/C1 controls except tab and malformed UTF-8 become
  U+FFFD); content outputs and `--json` stay raw.
- `output.uuidDefaultTextMode(id_format, explicit)`: ruling D7 text handles of `list-windows`,
  `current-window`, `new-window` and `current-workspace` (UUIDs unless `--id-format` is given);
  `output.bareWindowsArray(result)`: the bare `list-windows --json` array.
- `Platform.stdinIsTerminal()`, `Platform.fileSize(path)`, `Platform.writeFileAtomic(gpa, path,
  bytes)`: the stdin-only console check (`diff`, `todo set`, `paste`), the 32 MiB upload check and
  the ADR-5.6 atomic writer.
